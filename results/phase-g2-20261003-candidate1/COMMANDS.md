response valid/ready transfer. Index zero: **11 cycles = 407.407 ns**. Nonzero
warm-up and steady-state: **9 cycles = 333.333 ns**. There are 13 index-zero and

wire time. Registered response assertion is after the preceding clock edge:
that publication convention is 10/8 cycles as separately recorded in G1's
README; this suite measures the first subsequent sampling/transfer edge (11/9).
Do not combine these endpoint conventions or describe either as host round-trip
latency. Latency is observed here, never used to schedule production wiring.

For context only: nominal eight-byte request wire time is 80/115200 = 694.444 µs;
TX's 80 mandatory bit times at divisor 234 = 693.333 µs, with one acceptance clock
between adjacent byte frames. Host/USB/software overhead and pauses are separate.
These calculations are not board latency measurements.
